Module Sc_project.Statistics

A module managing tool statistics. They are stored in '.stat' files with a JSON format for each run.

type t

The internal type of statistics.

and tool_stats = {
  1. time : float;
  2. status : (unit, string) Stdlib.Result.t;
  3. tests_generated : int;
}
val make : dir:Sc_sys.File.dir -> run_num:int -> t

Creates a new stats value in dir. The file name is built from the run_number.

val report : stats:t -> tool:string -> tool_stats -> unit

Registers the statistics for a given tool. If statistics already existed for the tool, it is erased and replaced by the new value.

val save : t -> unit

Writes the registered statistics into the file.

val load_from : dir:Sc_sys.File.dir -> t list Lwt.t

Reads all the statistics finalized up to now.

val print : Stdlib.Format.formatter -> t -> unit

Prints the current statistics.
