Module Sc_config.Section

type _ section

The type of sections that induce configuration values of type 'a

type any_section =
  1. | Any : _ section -> any_section
val define : string -> entries:'a Eztoml.row list -> default:'a -> 'a section

define section_name ~entries ~default defines a new configuration section with name section_name, and TOML entires defined by entires. The default settings are given by default.

val update_section : 'a section -> 'a -> Toml.Types.table -> ('a, string) Stdlib.result

update_section section from table updates the options from for configuration section section using table.

val load_section : 'a section -> ?from:'a -> Toml.Types.table -> (unit, string) Stdlib.result

load_section section table updates the internal options for the given configuration section using table.

val load : Toml.Types.table -> (unit, string) Stdlib.result

load table updates the internal options for registered configuration sections using table.

val get : ?check_loaded:bool -> 'a section -> 'a

get ~check_loaded section retrieves the settings of the given section.

Note: unless check_loaded is explicitly set to false, load must have been called before. Otherwise, Errors.Unconfigured_section is raised.

val core_digest : unit -> Stdlib.Digest.t

core_digest () computes a digest of the non-runtime part of the currently loaded configuration.

val print_default_config_file : head:any_section list -> Stdlib.Format.formatter -> unit

Prints a TOML file that corresponds to the default options for all the registered sections.

Sections in head are printed first in the same order as in head; other sections are printed in lexicographic order.

val print_config_rst_doc : head:any_section list -> Stdlib.Format.formatter -> unit

Same as print_default_config_file in the RST documentation format.

val print_current_config_file : Stdlib.Format.formatter -> unit

Prints a TOML file that corresponds to the current set of options for all of the registered and configured sections.

val print_doc : head:any_section list -> Stdlib.Format.formatter -> unit

Prints the full documentation of the registered configuration sections.

See print_default_config_file for the purposes of head.

val as_section_update_cmdliner_term : ?with_section_name_prefix:bool -> 'a section -> 'a Cmdliner.Term.t -> 'a Cmdliner.Term.t

as_section_update_cmdliner_term ~with_section_name_prefix section section_term converts a configuration section into a Cmdliner term for parsing command-line arguments. If with_section_name_prefix holds, each long-option key for the section is prefixed with the section name and a `-`.

Note: an evaluation of the resulting term performs a functional update of a given record for a configuration section, but does not correspond to a call to load. In particular, the changes have no effect on the configuration section that load implicitly acts upon.

val as_toml_table_cmdliner_term : (any_section * [ `with_section_name_prefix | `without_section_name_prefix ]) list -> Toml.Types.table Cmdliner.Term.t

as_toml_table_cmdliner_term ~with_section_name_prefix sections is a Cmdliner term that converts command-line arguments into a corresponding TOML table for the given list of sections. If with_section_name_prefix holds, each long-option key for the section is prefixed with the section name and a `-`.
