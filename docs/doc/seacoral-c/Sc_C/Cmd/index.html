Specialized commands

In commands below:

  • clang_cmd is the name of the clang executable. It defaults to the value of Env.clang_exe, i.e $CLANG or else "clang";
  • clangxx_cmd is the name of the clang++ executable. It defaults to the value of Env.clangxx_exe, i.e $CLANGXX or else "clang++";
  • ld_cmd is the name of the linker executable. It defaults to the value of Env.clang_exe, i.e $CLANG or else "clang";
  • cppflags is a list of strings passed as arguments to the C per-processor (empty by default). Note the value of $CPPFLAGS (Env.cppflags) is always appended;
  • cflags is a list of strings passed as arguments to the C compiler (empty by default — not to be);
  • ldflags is a list of strings passed as arguments to the linker (empty by default). Note the value of $LDFLAGS (Env.ldflags) is always appended, except when LLVM bitcode is to be produced;
  • stdout_grabber and/or stderr_grabber may also be used to grab streams of lines output by the underlying compilation processes. This happens in addition to their inclusion in logs at debug level.

These commands may raise ERROR.

clang_check source_file uses clang to perform a syntax check on the given source file. Please refer to clang_c for semantics of named arguments.

val clang_c : ?clang_cmd:string -> ?cflags:string list -> ?cppflags:string list -> ?o_dir:Sc_sys.File.TYPES.dir -> ?o_suff:string -> ?stdout_grabber:Sc_sys.Process.stream_grabber -> ?stderr_grabber:Sc_sys.Process.stream_grabber -> [> `C ] Sc_sys.File.TYPES.file -> [ `O ] Sc_sys.File.TYPES.file Lwt.t

clang_c ?clang_cmd ?cflags ?cppflags ?osuff file starts the compilation of a given C file file, and returns a promise for the corresponding object file.

Starts the compilation of a C file and return the object file in an Lwt promise. If the compilation fails raises Failure. Param clang_cmd: the name of the clang executable (default: Config.Env.clang_exe). Param cflags: the compilation flags (default: "-g"). Parem o_suff: a string added between the file name and the ".o" file extension (clang_c ~osuff:"foo" "file.c" -> "filefoo.o")
