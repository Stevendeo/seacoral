Module PPrt.Record

  • Helpers for pretty printing records

Helpers for pretty printing records

type field

A record field.

val field : string -> 'a pp -> 'a -> field

field fname pp v

Defines a record field that will print v.

val optional_field : ?default:ufmt -> string -> 'a pp -> 'a option -> field

optional_field ?default fname pp v

Same as field but with an optional value. If no default value is given, will not print the record field if v = None.

val pp : field list pp

Prints a record.
