Project initialization

val project : ?clean_start:bool -> salt:Stdlib.Digest.t -> Types.config -> Sc_project.Types.project_config Lwt.t

project ~clean_start ~salt user_config validates a user-given configuration and initializes a project. This notably involves creating the associated working directory, if it does not exist already.
