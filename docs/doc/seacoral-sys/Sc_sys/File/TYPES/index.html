Module File.TYPES

type +_ file

The type of files. Having such a value ensures the file actually exists (unless it is removed by other means).

type dir = [ `dir ] file

An alias for directories

  1. context : string;
    (*

    describes when the error occured

    (*

    *)
  3. code : Unix.error;
  4. func : string;
  5. arg : string;
    (*

    as per Unix_error

    *)
}

exception UNIX_ERROR of unix_error
exception DRY_OPERATION_ERROR of string

Exception raised by err_if if called with dry=true. This is used when some operation that should be performed to properly setup a project is prevented due to the tool running in ``dry'' mode.
