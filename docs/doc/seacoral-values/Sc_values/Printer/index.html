Helpers to print C types and variable declarations

val c_typ : 'a Ctypes.typ Fmt.t

c_typ ppf typ prints a low-level `ctypes` type typ as parseable C code.

val c_decl : ('a Ctypes.typ * string) Fmt.t

c_decl ppf (typ, v) prints a low-level declaration of variable v as `ctypes` type typ as parseable C code.

val cil_typ : Cil.typ Fmt.t

cil_typ ppf typ prints a Cil. type [typ] as parseable C code.

val cil_decl : (Cil.typ * string) Fmt.t

cil_decl ppf (typ, v) prints a low-level declaration of variable v as Cil type typ as parseable C code.
